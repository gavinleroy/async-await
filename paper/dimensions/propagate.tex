\subsection{Propagation}\label{ssec:designdims:propagation} 

The Exception Propgation axis defines if an exception propagates out of \textit{unawaited} \tasks into the calling context. We define this axis strictly for unawaited \tasks because an exception always propagates at explicit synchronization points (i.e., await points). The possible values are: \textit{destruction}, and \textit{never.}

\begin{figure}[H]
  \begin{minipage}[t]{0.49\textwidth}
\begin{lstlisting}[language=Python]
import asyncio

async def inner():
    raise Exception()

async def main():
    i = asyncio.create_task(inner())
    await asyncio.sleep(0)
    print("exiting")

asyncio.run(main())
# "exiting"
# Task exception was never retrieved
# Exception
\end{lstlisting}
    \cprotect\subcaption{Python's Asyncio library reraises exceptions on destruction (program scoped). The above program prints ``exiting'' and then raises the exception \code{Bad} with an explanation, \textit{Task exception was never retrieved.}}
    \label{fig:designdims:propagation:never}
  \end{minipage}\hfill%
  \begin{minipage}[t]{0.49\textwidth}
\begin{lstlisting}[language=Swift]
enum Err: Error { case bad }

func inner() async throws {
  throw Err.bad
}

func work() async {
  async let _ = inner()
  try? await Task.sleep(
      for: .seconds(0))
  print("exiting")
}

await work() // "exiting"
\end{lstlisting}
    \cprotect\subcaption{Swift never reraises unawaited exceptions. The above program prints ``exiting'' and exits successfully.}
    \label{fig:designdims:propagation:destruction}
  \end{minipage}
  \caption{Examples of destruction and never exception propagation.}
  \label{fig:designdims:propagation}
\end{figure}

\Cref{fig:designdims:propagation:destruction} provides an example Python (Asyncio) program. Asyncio employes destruction exception propagation. The inner \task \code{inner}, throws an exception, however, the \task that launched it, \code{main}, never awaits it. On destruction, the \task reraises the unawaited exception. 

\Cref{fig:designdims:propagation:never} provides the same code in Swift, which demonstrates never propagating an exception unless it's awaited. Although swift enforces dynamic-extent (see \Cref{ssec:designdims:extent}), on destruction, a \task doesn't propagate exceptions.
